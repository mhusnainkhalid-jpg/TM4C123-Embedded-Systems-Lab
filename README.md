📌 Overview
This repository contains all lab experiments, an open-ended lab, and the final project completed as part of the EL3006 Embedded System Lab course at FAST NUCES. All experiments are implemented on the TM4C123GH6PM (Tiva C Series LaunchPad) microcontroller using Keil µVision 4, and verified on real hardware using an oscilloscope.
